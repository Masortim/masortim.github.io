Каталог и анализ беспилотниковA catalogue and analysis of UAVs

Проект собирает технические характеристики БПЛА и превращает их в структурированные данные для изучения и сравнения.The project gathers UAV technical specifications and turns them into structured data for exploration and comparison.

Задача и устройствоPurpose and design

В приложении используются SQLite и pandas для хранения и обработки данных, а Plotly — для интерактивной визуализации. Поля модели включают производителя, страну, тип, массу, полезную нагрузку, время полёта, скорость, дальность и другие параметры.

В коде предусмотрен сбор сведений из веб-источников: задействованы requests и BeautifulSoup, а Selenium подключается опционально для страниц, где нужен браузерный рендеринг. Такая комбинация показывает, почему сбор данных требует разделять извлечение, нормализацию и представление.

Для дальнейшего развития особенно важны происхождение и дата каждого значения, проверка единиц измерения и обработка конфликтующих источников. Это позволит трактовать диаграммы не только как наглядное сравнение, но и как проверяемую базу характеристик.

The app uses SQLite and pandas for data storage and processing, with Plotly for interactive visualizations. Model fields include manufacturer, country, type, mass, payload, flight time, speed, range, and other specifications.

The code includes web-data collection with requests and BeautifulSoup; Selenium is an optional path for pages that require browser rendering. This combination illustrates why extraction, normalization, and presentation need clear boundaries.

Provenance and timestamping for each value, unit validation, and handling conflicting sources are important next steps. They would make charts not only visual comparisons but views into a verifiable dataset.

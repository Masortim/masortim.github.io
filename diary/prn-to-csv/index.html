Из текстового PRN в CSVFrom text PRN to CSV

Задача конвертера — превратить столбчатый текстовый PRN-файл в строки CSV, пригодные для дальнейшей обработки.The converter turns column-oriented PRN text into CSV rows ready for further processing.

Задача и устройствоPurpose and design

Конвертер читает строки по очереди, разбивает их по пробелам и табуляциям, затем записывает полученные поля через запятую. В репозитории представлены реализации на C, C++ и C#, поэтому сам алгоритм можно сопоставить между языками.

В C#-варианте входной и выходной файлы задаются пользователем в консоли. Пример показывает практический путь данных от ввода имени файла до потокового преобразования — без необходимости загружать весь файл в память.

Стоит учитывать, что простое разделение не покрывает CSV-экранирование запятых, кавычек и локализованных чисел. Для универсального инструмента следующим этапом были бы явные правила формата, обработка ошибок ввода-вывода и тестовые файлы с крайними случаями.

The converter reads one line at a time, splits it on spaces and tabs, and writes the resulting fields separated by commas. Implementations in C, C++, and C# make it possible to compare the same algorithm across languages.

In the C# version, the input and output filenames are requested in the console. It demonstrates a practical data path from filename input to streaming conversion without loading an entire file into memory.

Simple splitting does not cover CSV quoting, commas inside values, or localized numbers. A more general tool would need explicit format rules, robust I/O errors, and fixtures for edge cases.

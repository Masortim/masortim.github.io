Одно приветствие — много языковOne greeting, many languages

Этот репозиторий собирает маленькие программы-приветствия, чтобы сравнивать формы записи в разных языках, не отвлекаясь на большие примеры.This repository gathers tiny greeting programs so that language syntax can be compared without the distraction of larger examples.

Задача и устройствоPurpose and design

Вместо одной большой программы здесь отдельный файл на каждый язык: рядом оказываются знакомые конструкции вывода, объявления и запуска. Минимальный размер примера особенно полезен, когда язык или инструмент встречается впервые.

Такая коллекция не претендует на исчерпывающий справочник: она фиксирует базовую точку входа. Чтобы поддерживать её, важно сохранять единый формат именования файлов и проверять, что примеры действительно запускаются соответствующими компиляторами или интерпретаторами.

Дальше каталог можно дополнить краткой таблицей языков и командами запуска — так от простого сравнения синтаксиса будет легко перейти к проверяемым экспериментам.

Rather than one large program, there is a separate file for each language, putting familiar output, declaration, and launch patterns side by side. Small examples are particularly helpful when encountering a language or tool for the first time.

This collection is not meant to be a complete reference; it captures the basic entry point. Consistent filenames and checking that examples run with their respective compilers or interpreters are what keep it useful.

A language index and short run commands would make a natural next addition, turning syntax comparison into reproducible experiments.

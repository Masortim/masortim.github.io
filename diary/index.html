ЗАПИСЬ 01 · НАЧАЛО

Начало журнала

21 ноября 2026 · Процесс разработки

Это не журнал коммитов. Здесь будут оставаться причины решений, наблюдения за поведением интерфейса и короткие итоги экспериментов. 1 Историю изменений по-прежнему показывает Git; дневник добавляет человеческий контекст.

Главная страница и адрес /diary/ ведут к этому дневнику, а интерактивное приложение остаётся доступно отдельно — по адресу /graph/. 2 Дневник публикуется вместе с графом через GitHub Pages; для записей не нужны отдельный сервер или база данных.

Каждая запись будет выходить на русском и английском. Переключатель вверху меняет язык страницы и запоминает выбор в этом браузере. 3 На узком экране нажмите на номер примечания, чтобы раскрыть его текст.

ENTRY 01 · BEGINNING

Starting the log

November 21, 2026 · Development process

This is not a commit log. It is a place to record why decisions were made, how the interface behaves, and what short experiments have taught us. 1 Git still records the changes; the diary adds the human context around them.

The site root and /diary/ lead to this diary, while the interactive application remains available separately at /graph/. 2 GitHub Pages publishes the diary alongside the graph; entries need no separate server or database.

Every entry will be available in Russian and English. The control above switches the page language and remembers the choice in this browser. 3 On a narrow screen, tap a note number to reveal its text.

Coming next

Future entries will document how the graph works, how proposals move through the app, and the reasoning behind interface decisions—including what has been verified and what still needs attention.

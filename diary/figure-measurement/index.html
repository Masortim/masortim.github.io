Измерение фигур на изображенииMeasuring shapes in an image

Эксперимент на Python объединяет обработку изображений и геометрию: от пиксельных контуров до размеров фигур.A Python experiment combines image processing and geometry, moving from pixel contours to shape measurements.

Задача и устройствоPurpose and design

Изображение сначала проверяется на DPI, чтобы оценить масштаб пикселей в сантиметрах; если метаданных нет, используется запасной масштаб. Затем изображение сглаживается, переводится в оттенки серого, а детектор Canny выделяет границы для поиска контуров.

Для каждого контура программа оценивает площадь, аппроксимирует полигон и вычисляет длины сторон. Если контур достаточно близок к кругу по сравнению с описанной окружностью, вместо периметра выводится длина окружности. В наборе примеров есть круг, прямоугольник, квадрат, звезда и треугольник.

Точность зависит от качества границ, разрешения, DPI и выбранного порога приближения к окружности. Поэтому измерения лучше рассматривать как оценку; перспективная доработка — калибровочный объект и визуализация найденных контуров поверх исходного изображения.

The image is checked for DPI so pixel distances can be estimated in centimetres; a fallback scale is used when metadata is absent. The image is then smoothed, converted to grayscale, and passed through Canny edge detection before contours are found.

For each contour, the program estimates area, approximates a polygon, and calculates side lengths. If the contour is sufficiently close to a circle relative to its enclosing circle, it reports circumference instead of perimeter. Example images include a circle, rectangle, square, star, and triangle.

Accuracy depends on edge quality, resolution, DPI, and the chosen circularity tolerance. Results are best treated as estimates; a calibration object and an overlay of detected contours would be useful next steps.

Математические формулы

Стиль Tufte отлично подходит для документов с математическими формулами. Формулы могут быть инлайн или блочными. 1 MathJax уже подключен в этом документе. Используйте \(...\) для инлайн формул и \[...\] для блочных формул.

Инлайн формула: согласно первой фундаментальной теореме математического анализа, для \(x\) в \([a, b]\): \(\frac{d}{dx}\left( \int_{a}^{x} f(u)\,du\right)=f(x)\). Мы знаем из первой фундаментальной теоремы математического анализа, что для \(x\) в \([a, b]\): \[\frac{d}{dx}\left( \int_{a}^{x} f(u)\,du\right)=f(x).\]

Блочная формула отображается на отдельной строке: \[\frac{d}{dx}\left( \int_{a}^{x} f(u)\,du\right)=f(x).\]

Формула Эйнштейна для эквивалентности массы и энергии: \[E = mc^2\]

Более сложная формула с интегралом: \[\int_{-\infty}^{\infty} e^{-x^2} dx = \sqrt{\pi}\]

Формула может быть размещена в полноширинном блоке:

\[f(x) = \sum_{n=0}^{\infty} \frac{f^{(n)}(a)}{n!}(x-a)^n\]

Ряд Тейлора для функции \(f(x)\) в точке \(a\)

JavaScript (ES6+)

Этот пример демонстрирует использование классов в JavaScript ES6. 

// Определение класса для работы с данными
class DataProcessor {
  constructor(data) {
    this.data = data;  // Инициализация данных
    this.processed = false;  // Флаг обработки
  }
  
  // Метод для обработки данных
  process() {
    if (this.processed) {
      return this.data;  // Возврат, если уже обработано
    }
    
    // Преобразование данных
    this.data = this.data.map(item => ({
      ...item,
      processed: true,
      timestamp: Date.now()
    }));
    
    this.processed = true;
    return this.data;
  }
  
  // Метод для получения статистики
  getStats() {
    return {
      count: this.data.length,
      processed: this.processed
    };
  }
}

// Использование класса
const processor = new DataProcessor([{id: 1}, {id: 2}]);
processor.process();
console.log(processor.getStats());

TypeScript

interface User {
  id: number;
  name: string;
  email: string;
}

class UserService {
  private users: User[] = [];
  
  addUser(user: User): void {
    this.users.push(user);
  }
  
  findUserById(id: number): User | undefined {
    return this.users.find(user => user.id === id);
  }
  
  getAllUsers(): User[] {
    return [...this.users];
  }
}

const service = new UserService();
service.addUser({ id: 1, name: "Иван", email: "ivan@example.com" });
console.log(service.getAllUsers());

Python (с асинхронностью)

import asyncio
from typing import List, Dict

async def fetch_data(url: str) -> Dict:
    """Асинхронная загрузка данных"""
    await asyncio.sleep(1)  # Имитация сетевого запроса
    return {"url": url, "data": "example"}

async def process_multiple_urls(urls: List[str]) -> List[Dict]:
    """Обработка нескольких URL параллельно"""
    tasks = [fetch_data(url) for url in urls]
    results = await asyncio.gather(*tasks)
    return results

# Использование
async def main():
    urls = ["http://example.com/1", "http://example.com/2"]
    results = await process_multiple_urls(urls)
    print(results)

asyncio.run(main())

C

#include <stdio.h>
#include <stdlib.h>

// Структура для представления точки
typedef struct {
    double x;
    double y;
} Point;

// Функция для вычисления расстояния между точками
double distance(Point p1, Point p2) {
    double dx = p2.x - p1.x;
    double dy = p2.y - p1.y;
    return sqrt(dx * dx + dy * dy);
}

int main() {
    Point p1 = {0.0, 0.0};
    Point p2 = {3.0, 4.0};
    
    double dist = distance(p1, p2);
    printf("Расстояние: %.2f\n", dist);
    
    return 0;
}

Bash

#!/bin/bash

# Скрипт для резервного копирования
BACKUP_DIR="/backup"
SOURCE_DIR="/home/user/documents"
DATE=$(date +%Y%m%d_%H%M%S)

# Создание директории для бэкапа
mkdir -p "$BACKUP_DIR"

# Архивирование
tar -czf "$BACKUP_DIR/backup_$DATE.tar.gz" "$SOURCE_DIR"

# Проверка успешности
if [ $? -eq 0 ]; then
    echo "Резервное копирование успешно завершено"
    # Удаление старых бэкапов (старше 7 дней)
    find "$BACKUP_DIR" -name "backup_*.tar.gz" -mtime +7 -delete
else
    echo "Ошибка при создании резервной копии"
    exit 1
fi

Специальное форматирование текста

В стиле Tufte можно использовать различные способы выделения текста:

  • Жирный текст для важных моментов
  • Курсив для акцента
  • Санс-сериф шрифт для выделения
  • Моноширинный код для технических терминов
  • Капитель для начала новых мыслей
  • Красный текст для предупреждений

Комбинации форматирования также возможны: жирный курсив, жирный код, и другие варианты.

Работа с длинным контентом

Стиль Tufte отлично подходит для длинных документов с множеством боковых заметок и иллюстраций. Широкие поля позволяют размещать дополнительную информацию, не отвлекая от основного текста.

Документ может содержать множество секций, каждая со своими заголовками, параграфами, изображениями и заметками. 5 Это пятая боковая заметка в документе, демонстрирующая возможность множественных ссылок.

Полноширинные блоки могут использоваться для важных объявлений или специальных разделов, которые требуют больше внимания.

Важное примечание: Этот блок использует полноширинную ширину и может содержать любую важную информацию, которая должна выделяться на странице. Фон и граница помогают привлечь внимание.

После полноширинных блоков основной текст продолжается в обычном формате.

Введение

Стиль Tufte Handout был разработан Эдвардом Тафти для своих книг и раздаточных материалов. Этот стиль известен широким использованием боковых заметок, тесной интеграцией графики с текстом и качественной типографикой. 1 См. репозитории на GitHub: tufte-latex и tufte-css

В своих более поздних книгах 2 Например, "Beautiful Evidence" Тафти начинает каждую секцию с небольшого вертикального отступа, неотступного параграфа и устанавливает первые несколько слов предложения капителью.

Заголовки

Этот стиль предоставляет заголовки первого и второго уровня (то есть h1 и h2), которые демонстрируются в этом разделе. Заголовки автоматически отображаются курсивом.

Код и примеры

В стиле Tufte код отображается с использованием моноширинных шрифтов. Вот пример инлайн кода: const example = "Hello, World!";

Также поддерживаются математические формулы: простая инлайн формула \(E = mc^2\) или более сложная блочная формула: \[\int_{0}^{\infty} e^{-x^2} dx = \frac{\sqrt{\pi}}{2}\]

Блоки кода отображаются с сохранением форматирования и подсветкой синтаксиса:

JavaScript

Код выводит в консоль приветствие с подставленным именем — в данном случае «Привет, Мир!». 

function greet(name) {
  console.log(`Привет, ${name}!`);
}

greet("Мир");

Python

На экран выводится строка: Привет, Мир!

Функция возвращает список [1, 4, 9, 16, 25] (но этот результат нигде не сохраняется и не выводится, так как вызов функции не присвоен переменной и не передан в print()). 

def greet(name):
    """Приветствие пользователя"""
    print(f"Привет, {name}!")
    
    # Пример работы со списками
    numbers = [1, 2, 3, 4, 5]
    squares = [x**2 for x in numbers]
    return squares

greet("Мир")

Java

При запуске программы в консоли появится строка: Привет, Мир!

Ключевые особенности реализации: Используется инкапсуляция: поле name закрыто (private), доступ к нему возможен только через методы класса.
Конструктор обеспечивает инициализацию объекта при создании.
Метод greet() использует сохранённое состояние объекта (поле name) для формирования вывода.
Статический метод main демонстрирует создание и использование объекта класса Greeter. 

public class Greeter {
    private String name;
    
    public Greeter(String name) {
        this.name = name;
    }
    
    public void greet() {
        System.out.println("Привет, " + name + "!");
    }
    
    public static void main(String[] args) {
        Greeter greeter = new Greeter("Мир");
        greeter.greet();
    }
}

C++

При запуске программы в консоли появится строка: Привет, Мир!

Ключевые особенности: Инкапсуляция: поле name приватное (private), доступ только через методы класса.
Эффективная передача параметров: использование константной ссылки (const std::string&) в конструкторе избегает лишнего копирования строки.
Инициализация через список: конструктор использует список инициализации (: name(name)), что предпочтительнее присваивания в теле конструктора.
Стандартные потоки: вывод реализован через std::cout и std::endl из библиотеки <iostream>. 

#include <iostream>
#include <string>

class Greeter {
private:
    std::string name;
    
public:
    Greeter(const std::string& name) : name(name) {}
    
    void greet() {
        std::cout << "Привет, " << name << "!" << std::endl;
    }
};

int main() {
    Greeter greeter("Мир");
    greeter.greet();
    return 0;
}

SQL

Код создаёт структуру для хранения пользователей, добавляет одного пользователя и формирует отчёт о количестве заказов для каждого пользователя (включая тех, у кого заказов нет). 

-- Создание таблицы пользователей
CREATE TABLE users (
    id INT PRIMARY KEY AUTO_INCREMENT,
    name VARCHAR(100) NOT NULL,
    email VARCHAR(255) UNIQUE,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- Вставка данных
INSERT INTO users (name, email) 
VALUES ('Иван', 'ivan@example.com');

-- Запрос с JOIN
SELECT u.name, u.email, COUNT(o.id) as order_count
FROM users u
LEFT JOIN orders o ON u.id = o.user_id
GROUP BY u.id, u.name, u.email;

Таблицы

Таблицы в стиле Tufte имеют простой дизайн с границами сверху и снизу. Подписи таблиц размещаются на полях, как и подписи к изображениям.

Пример таблицы с данными.

Блочные цитаты

Блочные цитаты в стиле Tufte занимают 50% ширины основного текста и могут включать подпись автора, выровненную справа.

"Если бы не мой адвокат, я бы все еще был в тюрьме. С двумя людьми копать получалось намного быстрее."

— Джо Мартин

Цитаты также могут быть без подписи автора:

"Великие люди говорят об идеях, средние люди говорят о вещах, а маленькие люди говорят о вине."

— Фрэн Лебовиц

Списки

Списки в стиле Tufte имеют специальное форматирование:

  1. Первый элемент нумерованного списка
  2. Второй элемент с дополнительной информацией
  3. Третий элемент списка

Маркированные списки также поддерживаются:

  • Элемент маркированного списка
  • Еще один элемент
  • И еще один элемент

Адаптивность

HTML страница адаптивна в том смысле, что когда ширина страницы меньше 760px, боковые заметки и заметки на полях скрываются по умолчанию. Для боковых заметок вы можете кликнуть на их номера (надстрочные числа), чтобы переключить их видимость. Для заметок на полях вы можете кликнуть на символы ⊕, чтобы переключить видимость.

Дополнительные возможности

Вы можете использовать санс-сериф шрифт для выделения текста.

Для важных предупреждений можно использовать класс danger, который отображает текст красным цветом.
